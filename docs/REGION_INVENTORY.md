Reject tenant/MG IDs for this selected-subscription helper. Preserve source display fields, including formula-like names; don't require displayed name/type/group to derive from the ID. Later collector owns actual resource consistency.

Duplicate IDs case-insensitively reject. Real lowercase row SubscriptionID remains out-of-band correlation, as existing pure helpers do; display cells use the mask flag. The future canonical builder/privacy path must mask correlation before serializing public artifacts. Masking is not anonymization or a guarantee that arbitrary labels contain no identifier.
